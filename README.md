# Тренажёр: нормальная физиология

4440 тестовых вопросов кафедры нормальной физиологии: 18 тем, 38 тестов, 85 иллюстраций.
Открыть `index.html` в браузере или через GitHub Pages.

- `index.html` — приложение
- `data.js` — вопросы и ответы
- `img/` — иллюстрации к вопросам
- `fonts/` — шрифты дизайн-системы

Режимы: тест целиком по порядку, диапазон вопросов, случайные N, «по билетам» (для зачёта по крови),
30 случайных из всех тем, работа над ошибками, список всех вопросов с ответами и поиском.
Прогресс (ошибки, лучший результат, решения на 100%) хранится в браузере.

Вопросы взяты из тренажёра https://olmer711.github.io/SGMU/norm_physiology_trainer.html.
